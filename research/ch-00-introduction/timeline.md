# Introduction timeline

Dates below organize research. They are not yet approved manuscript claims.

| Date | Event | Why it matters here | Source |
|---|---|---|---|
| 1703 | Leibniz presents arithmetic using the characters 0 and 1 | A compact symbolic representation becomes a general arithmetic system | Leibniz original scan |
| 1936--1937 | Turing defines computation through a finite symbolic machine and publishes the paper | A small rule system denotes an unbounded family of executions | Turing, DOI 10.1112/plms/s2-42.1.230 |
| 1945 | The EDVAC draft describes a stored-program organization | Instructions and data meet in a concrete machine design; attribution needs careful treatment | von Neumann, EDVAC draft |
| 1964-04-07 | IBM announces System/360 | A stable architecture connects multiple implementations and makes compatibility economically central | IBM System/360 history |
| 2010 | The RISC-V project begins at UC Berkeley | A new open ISA offers a modern sustained RISC comparison | Verify against primary RISC-V history before prose |
| 2019 | The RISC-V unprivileged base specifications reach ratified status | The teaching slice can be pinned to a public specification | RISC-V ratified specifications library |
| 2026 | This project defines A0 and a claim/evidence ledger | The book can separate teaching definitions from current real-ISA facts | Repository objects and `MASTER.md` |
