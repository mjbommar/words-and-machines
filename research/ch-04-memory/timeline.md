# Chapter 4 timeline

Dates organize research; they do not by themselves authorize priority claims.

| Date | Event | Relevance | Source |
|---|---|---|---|
| 1945 | The EDVAC draft treats memory as an organ that retains numerical material and orders | Stored programs need addressable retained information | EDVAC report |
| 1947--1948 | Williams and Kilburn describe and test regenerative cathode-ray storage | A physical bit requires writing, sensing, retention, and regeneration | Kilburn report; Williams and Kilburn letter |
| 1949--1950s | Wang, Rajchman, Forrester, and others develop magnetic-core methods amid patent disputes | Random-access storage joins physical selection geometry, manufacturing labor, and compatibility | Computer History Museum archive |
| 1962 | Atlas's one-level storage system is published | Automatic block movement and address translation hide a fast-core/drum hierarchy from ordinary programs | Kilburn et al. paper |
| 1967--1968 | Dennard files and receives the field-effect-transistor memory patent | A compact semiconductor cell stores charge but requires periodic regeneration | US Patent 3,387,286 |
| 2023 | CS2023 treats hierarchy, virtual memory, protection, performance, energy, and reliability as core architecture concerns | Modern memory education must cross the ISA, operating-system, and physical boundaries | ACM/IEEE-CS/AAAI curriculum |
| 2023--2026 | Government memory-safety guidance and current RISC-V/Intel manuals document security and compatibility obligations | Address validity, object safety, translation, permissions, and faults remain live industrial contracts | CISA guidance; pinned architecture manuals |
