# Chapter 5 timeline

Dates organize research; they do not by themselves authorize priority claims.

| Date | Event | Relevance | Source status |
|---|---|---|---|
| 1936--1937 | Turing describes machines through finite behavior tables whose symbolic work may continue indefinitely | Finite description can govern unbounded computation | London Mathematical Society paper opened |
| 1940s | Stored-program designs make instruction selection and conditional transfer part of addressed machine state | Control paths become data-dependent machine behavior | Contemporary sources to reconcile |
| 1947 | Goldstine and von Neumann use flow diagrams to organize computations | Program paths become explicit objects of reasoning | IAS report opened |
| 1966 | Böhm and Jacopini publish a representation result for flow diagrams | Sequence, selection, and iteration become a foundation for structured control | Primary paper opened |
| 1967 | Floyd presents inductive assertions for flowcharts | Local assertions support global program proofs | Primary paper opened |
| 1969 | Hoare presents an axiomatic basis for program reasoning | Preconditions, commands, and postconditions become compositional proof objects | ACM record and paper opened |
| 2000s--2020s | Compiler CFG analyses, hardware prediction, trace tooling, and control-flow integrity mature | Control paths carry optimization, performance, evidence, and security costs | Current official sources to open |
| 2026 | Current RV64 and x86-64 specifications retain distinct direct and indirect control contracts | A0 requires explicit refinement premises for both companion machines | Current manuals to open |
