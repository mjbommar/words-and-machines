# Chapter 2 timeline

Dates organize research; they do not by themselves authorize manuscript
claims.

| Date | Event | Relevance | Source |
|---|---|---|---|
| 1938 | Shannon analyzes relay and switching circuits with symbolic logic | Combinational switching has an algebraic account; retained state additionally needs feedback or storage | Shannon paper |
| 1945 | The EDVAC draft describes arithmetic, control, memory, input, and output organs | A stored program requires retained information sufficient to continue an ordered computation | EDVAC report |
| 1956 | Moore publishes experiments on finite sequential machines | Internal states are compared by the input experiments and output sequences that can distinguish them | Moore chapter |
| 1964 | Amdahl, Blaauw, and Brooks publish the System/360 architecture account | Architecture fixes the programmer-visible contract across different implementations | IBM Journal paper |
| 2019--2026 | Ratified RISC-V revisions preserve the base integer state contract while adding optional extensions | Architectural state is modular rather than one undifferentiated inventory | Pinned RISC-V manual |
| 2026 | Intel SDM version 092 documents basic, extended, system, and model-specific state in separate volumes | A mature compatible architecture imposes layered state-management obligations | Intel SDM landing page and manuals |
