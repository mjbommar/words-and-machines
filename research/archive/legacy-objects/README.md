# Superseded object ledger

These 47 records formed the evidence-led draft before the book was rebuilt
around A0, RV64, and x86-64. They are retained only as research provenance.

They are not read by the active ledger generator, do not generate chapter
status macros, and do not define the active Axeyum artifact architecture. The
vector-shuffle, processor-cost, permutation, and old Bitmanip records must not
be cited as active book results.

See the active object schema and the clean-sheet Axeyum evidence outline for
the replacement design.
