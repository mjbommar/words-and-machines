# Chapter 6 chronology

This chronology separates ideas, documented designs, working machines,
standardization, and current specification. Dates and priority language must
be checked against opened sources before manuscript use.

| Date | Development | Relevance and caution |
|---|---|---|
| 1940s | Early electronic computers are configured through switches, cables, panels, tables, or external media | The contrast explains why stored instruction words matter; machines and methods differed |
| 1945 | EDVAC report circulates a stored-program design | A design document and dissemination milestone, not a completed EDVAC execution date or sole-inventor event |
| 1948 | Manchester Small-Scale Experimental Machine runs a stored program | Working-machine milestone; connect finite instruction words to physical memory |
| 1949 | EDSAC performs practical stored-program calculations | Connect orders, initial loading, paper tape, and reusable program practice |
| 1951 | Wilkes, Wheeler, and Gill publish an early programming textbook | Check the primary text before describing its notation or order code |
| 1964 | IBM announces System/360 | A major compatibility family with explicit instruction formats; distinguish architecture announcement from later implementations |
| 1970s | Microprocessor instruction sets accumulate compact and mode-dependent encodings | Avoid treating later x86-64 structure as present in the first generation |
| 1980s | RISC projects foreground regular instruction formats and compiler cooperation | Regularity is a design cluster, not a universal fixed-length law |
| 2000s | x86 frontends increasingly translate complex instruction bytes into internal operations | Microarchitecture-specific; do not place internal operations in ISA semantics |
| 2010s | RISC-V standardizes base formats and optional compressed instructions | Shows that regular base words and code-density extensions can coexist |
| 2026 | Current RISC-V and Intel manuals pin the examples in this chapter | All legality, mode, and extension claims remain version-scoped |
