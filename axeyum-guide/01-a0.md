# A0 semantic packages

Implementation proceeds in dependency order.

## A0 words

Provide width-parametric modular words, signed and unsigned readings, bit
operations, extension, truncation, and byte split and join. The public
interface must serve executable examples and proof reconstruction.

Controls change an edge result, extension rule, or byte exponent.

## A0 state

Provide eight registers, finite byte memory, program counter, Z N C V bits,
and running, halted, or trapped outcomes. Provide typed observations and state
projection.

Controls omit an observed component and accept an invalid memory range.

## A0 step

Provide instruction data types, operand validation, read and write sets,
encoding, decoding, and complete transitions. Decode failure and execution
traps remain distinct.

Controls use a wrong destination, hidden write, program-counter increment,
branch target, byte order, and execution after trap.

## A0 run

Provide bounded traces and terminating execution. Return halt, trap, bound
exhaustion, and continued execution as distinct results.

The first promoted artifact should be a byte split and join round trip.
Addition, memory round trip, and a conditional-branch trace follow. Each one
consumes versioned package digests rather than duplicating semantics in a
formula.
