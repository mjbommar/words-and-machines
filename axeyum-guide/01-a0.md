# A0 semantic packages

The concrete package and the first evidence routes are implemented. The
sections below distinguish those surfaces from the remaining theorem work.

## A0 words

`axeyum-machine` provides width-parametric modular words, signed and unsigned readings, bit
operations, extension, truncation, and byte split and join. The public
interface must serve executable examples and proof reconstruction.

The active finite computation exhausts byte split and join at widths 8 and 16.
Its control reverses byte order. General extension, truncation, and
arbitrary-width word theorems remain open.

## A0 state

The package provides eight registers, finite byte memory, program counter, Z N C V bits,
and running, halted, or trapped outcomes. Provide typed observations and state
projection.

Active routes separate narrow and broad observations, replay dense and sparse
atomic store/load traces, and audit the canonical complete-state codec. A
source-derived symbolic route proves the load/store frame laws at every
supported width. Its control commits a partial sparse write before a trap;
the symbolic negation becomes satisfiable and the concrete encoded step
exposes the changed byte.

## A0 step

The package provides instruction data types, operand validation, read and write sets,
encoding, decoding, and complete transitions. Decode failure and execution
traps remain distinct.

The decoder route exhausts all 41,409 legal structured instructions. Step
coverage executes every instruction family, all declared trap classes, and
terminal stuttering while checking exact effects and frame containment.
Controls use a wrong destination, hidden write, program-counter increment,
branch target, byte order, and execution after trap.

## A0 run

The package provides bounded traces. It returns halt, trap, bound
exhaustion, and continued execution as distinct results.

The active runner route covers all four classifications, a zero-step bound,
prefix resumption, and prefix composition. It does not prove program
termination.

## A0 symbolic addition

Concrete A0 `add` and symbolic addition instantiate one domain-parametric
operation structure. The evidence route proves agreement with the declared
result and Z N C V predicates separately at widths 8, 16, 24, 32, 40, 48, 56,
and 64. Replay rebuilds the Boolean terms, binds them to deterministic CNF,
and checks LRAT and DRAT. Inverting carry makes the formula satisfiable; a
complete width-eight evaluator finds `(0, 0)` and encoded A0 execution replays
the disagreement.

The symbolic domain adapter and term-to-CNF lowering remain trusted
reductions. Subtraction, shifts, other arithmetic operations, and kernel
reconstruction remain open.
